# CobbleBrain 1.6.1 한국어 메시지 애드온 - 개발용 시제품

**주의: 완성된 설치용 모드가 아닙니다.** 소스 코드 프로젝트입니다. Minecraft/Fabric 환경에서 빌드 및 게임 테스트를 마치지 않았으므로 실제 작동을 보장하지 않습니다.

## 목적
CobbleBrain이 번역 키를 사용하지 않고 직접 전송하는 다음 채팅 메시지를 화면에서 한국어로 치환합니다.
- `Friendship Staravia: +1` → `찌르버드 친밀도 +1`
- `Staravia spotted a Shipwreck at X:480 Y:-64 Z:912` → `찌르버드 — 정찰 중 발견: 난파선 (X:480 Y:-64 Z:912)`
- `Staravia completed its reconnaissance.` → `찌르버드가 정찰을 마쳤습니다.`
- `Charizard: 크와앙! (들뜸)` → `리자몽: 크와앙! (들뜸)`

## 한계
- 텍스트가 채팅 HUD에 도달했을 때만 치환하며 실제 AI 프롬프트/서버 데이터는 수정하지 않습니다.
- 이름 사전은 현재 예시 14종만 포함합니다. 전체 포켓몬 한글명 사전은 추후 추가해야 합니다.
- AI가 생성한 `도치!` 같은 울음소리를 수정하지 않습니다.
- 채팅 색상/클릭 이벤트/복합 Text 스타일은 완전히 유지되지 않을 수 있습니다.
- 다른 모드에서 동일한 문구를 출력하면 함께 치환할 가능성이 있습니다.

## 개발 환경
- Java 21, Gradle 8.x 필요
- Fabric Loom의 원격 의존성 다운로드를 위한 인터넷 연결 필요
- 예시 빌드: `gradle build`
- 빌드 성공 시 `build/libs/cobblebrain-korean-addon-0.1.0.jar` 후보를 `mods`에 설치하고 테스트
- **원본 CobbleBrain JAR는 변경하지 마세요.**

## 중요
이 ZIP은 `mods` 폴더에 바로 넣는 파일이 아닙니다. 실행 가능한 패치라고 안내하지 마세요.
